# Коллекция математических подходов

> Спек: `memory-bank/specs/approaches.md`; термины — `memory-bank/_terms.md`, контекст
> `approach`. Этот файл — рабочая коллекция, не спек.

Каталог математических идей, обнаруженных при разборе уже решённых задач для целей объяснения —
не путать с `TRICKS.md` в корне репозитория (тот про приёмы УСКОРЕНИЯ вычисления, найденные в
ходе исследовательского процесса; этот — про идеи, которые стоит проговорить, объясняя решение
человеку, независимо от того, ускоряют они что-то или нет). Схема записи:

```
### <название подхода>

Суть: <одна фраза, без формул>
Когда узнаётся: <по каким признакам в условии задачи виден именно этот подход>
Общий случай: <как выглядит идея не для конкретных чисел, а вообще>
Визуализируется: <ссылки на visualizations/<slug>.md — чем этот подход показывают; «—», если
картинки ещё нет: это сигнал завести её, не оставлять подход без визуализации>
Использовано в: <euler{NNN}, ...>
```

Связь с каталогом визуализаций двусторонняя: каждый подход перечисляет свои картинки, каждая
картинка в `visualizations/<slug>.md` полем `Approach:` называет свой подход. Визуализация, за
которой подхода нет (сейчас — `visualizations/skip-counting.md`: показывает само понятие «кратно»,
подготовительный шаг, а не способ счёта), помечается в своём спеке явно — подход под неё не
изобретается.

## Записи

### Включение-исключение

Суть: посчитать по отдельности, потом вычесть то, что посчитано дважды.
Когда узнаётся: в условии есть «или» между двумя (и более) свойствами числа/объекта
(«кратно A ИЛИ кратно B»).
Общий случай: для k условий сумма считается со знаками плюс-минус по всем их пересечениям
(попарным, тройным и так далее) — не только «А+Б−АБ», это лишь случай k=2.
Визуализируется: [visualizations/bar-model.md](visualizations/bar-model.md) (арифметическая
форма — из каких чисел состоит каждая часть), [visualizations/venn.md](visualizations/venn.md)
(пространственная форма — что общая часть вообще есть)
Использовано в: euler001

### Замкнутая формула суммы арифметической прогрессии

Суть: сумму чисел, идущих с равным шагом, можно получить одним умножением, не складывая их по
одному.
Когда узнаётся: нужно посчитать сумму (не количество) чисел, кратных чему-то, на отрезке.
Общий случай: сумма первых m членов прогрессии с шагом k равна `k · m·(m+1)/2`, где m — сколько
таких чисел вообще есть на отрезке; работает при любых k, m, N.
Визуализируется: [visualizations/gauss-pairing.md](visualizations/gauss-pairing.md)
Использовано в: euler001
